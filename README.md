# Personal Finance Tracker

A browser-based personal finance dashboard built with HTML, CSS, vanilla JavaScript, and IndexedDB.

## Run locally

Open `index.html` in a modern desktop browser. Your financial records stay in that browser's local IndexedDB storage; no backend or account is required.

## Features

- Income and expense tracking with search and filters
- Monthly budgets and financial goals
- Recurring transactions
- Reports, CSV import/export, and JSON backup/restore
- PGK currency by default, with other currency options

The app does not send transaction data to a server. Back up your data from **Import / Export** or **Settings** if you want to move it to another browser or computer.
